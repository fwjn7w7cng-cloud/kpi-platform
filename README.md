# kpi-platform

Платформа KPI-ботов для оптовых компаний: ядро + модули + папка с настройками на каждого клиента.
Один код на всех; у каждого клиента свой бот, своя база, свой процесс.

- `core/` — ядро (данные, KPI, зарплата, цикл месяца, экраны, роли, редакции, расписание, мессенджер)
- `modules/` — платные модули
- `clients/<клиент>/` — `config.yaml`, парсер его 1С, его особые правила
- `clients/demo/` — вымышленная фирма для показа

Подробно — в `CLAUDE.md`, история работ — в `JOURNAL.md`.

python3 -m unittest discover -s tests -v
