# AGENTS.md — для любого помощника-программиста (Codex и др.)

Проект ведётся по одной памятке: **прочитай `CLAUDE.md` целиком перед любой работой** — там всё: что это (платформа «Алапа»
для KPI-ботов оптовых компаний), как устроено ядро и папки клиентов, пакеты и цены, демо, сервер, выкатка, проверки.
Имена «Альфред» (на сервере) / «Джарвис» (в чате) в памятке — прежние помощники; правила для них действуют и для тебя.

## С чего начать
1. `CLAUDE.md` — спецификация и правила (обязательно целиком).
2. `JOURNAL.md` — журнал работ, новые записи сверху. Прочитай верхние.
3. `git log --oneline -20` — последние изменения.
4. `README.md` — коротко о проекте.

## Главное из правил (подробно — в CLAUDE.md)
- Владелец — Адам, не программист: по-русски, простыми словами, на «ты», суммы полностью (15 323 000).
- **Никаких изменений без его «да»**: сначала коротко — что изменится и зачем.
- **Ядро не знает клиентов:** в `core/` и `modules/` нет имён, фирм и их правил — всё конкретное в `clients/<клиент>/`
  (нужно особое — крючок в `core/hooks.py`, правило в `rules.py` клиента).
- Код — только через git: ветка → тесты → fast-forward в `main` → push. Никогда `push --force` в `main`.
- Тесты перед каждым пушем: `python3 -m unittest discover -s tests -v` — всё зелёное.
- Секреты (`.env` клиентов, ключи) — не в git, не показывать, не просить вставлять в чат.
- Бот Теплокома (`quizbot`) — отдельный проект, его репозиторий, сервер и базу не трогать.
- После заметной работы — запись сверху в `JOURNAL.md` (дата и время по Москве, кто, 1–3 строки).
